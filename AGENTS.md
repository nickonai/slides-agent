# Презентатор — правила для агентов

Работай на русском, если пользователь не попросил другой язык. Для создания
презентаций прочитай [единый процесс и правила](skills/slides/references/workflow.md)
и [справочник типов слайдов](skills/slides/references/slide-types.md).

Claude Code и Codex используют один и тот же навык в `skills/slides/`.
Собранные презентации хранятся в `presentations/<slug>/` и не коммитятся
без прямого запроса пользователя.
