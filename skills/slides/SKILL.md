# Презентатор

Прочитай [единые правила](references/workflow.md) и [типы слайдов](references/slide-types.md). Они применяются в Claude Code, Codex и загружаемом навыке ChatGPT. Явное пожелание пользователя имеет приоритет над настройками по умолчанию.

`SLIDES` — эта папка. Сценарий и результаты клади в рабочую папку пользователя `presentations/<slug>/`, а не внутрь навыка. Используй `scripts/build_deck.py` для сборки. Если нужных Python-пакетов или браузера нет, установи их через `scripts/setup.sh` либо `scripts/setup.ps1`, когда среда позволяет. Если среда не позволяет установку, попробуй `--html-only` и честно перечисли недоступные форматы.

Для Claude Code: аргументы `/slides` считай запросом пользователя. Для Codex и ChatGPT: обычное сообщение «сделай презентацию» запускает тот же процесс. Любой доступный инструмент просмотра изображений подходит для проверки каждого PNG.
